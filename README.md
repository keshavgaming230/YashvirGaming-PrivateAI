# ⚡ YashvirGaming Private AI Agent

A lightweight, cyberpunk-styled PySide6 desktop client built for coding, debugging, and general Q&A using free OpenRouter AI endpoints.

</div>

---

## ✨ Key Features

* **100% Free AI Access:** Connects directly to OpenRouter's free tier models (`poolside/laguna-s-2.1:free`, `google/gemma-4-31b-it:free`, etc.).
* **Drag & Drop File Context:** Drop `.txt`, `.py`, `.json`, or `.md` files directly into the window to analyze and fix code instantly.
* **Rich Markdown Formatting:** Automatically renders response code blocks inside styled code containers.
* **Local Key Security:** Loads API keys dynamically from a local `api_key.txt` file without hardcoding secrets.
* **Cyberpunk UI:** Built with PySide6, featuring high-contrast neon accents and real-time connection status indicators.

## 🛠️ Prerequisites & Installation

### 1. Clone the Repository
```bash
git clone [https://github.com/keshavgaming230/YashvirGaming-PrivateAI.git](https://github.com/keshavgaming230/YashvirGaming-PrivateAI.git)
cd YashvirGaming-PrivateAI

pip install -r requirements.txt
```
